# Portfolio Serverless API

A serverless REST API built with Node.js, Express, MongoDB, and Cloudinary, deployed on Vercel.

## 🚀 Features

- Serverless architecture (Vercel)
- MongoDB with connection caching
- Cloudinary for image uploads
- CORS enabled
- RESTful API endpoints

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/sazeduzzaman/myPortfolioServer
cd portfolio-api

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Edit .env with your credentials
